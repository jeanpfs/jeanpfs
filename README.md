# Hi, I'm Jean 👋

I build open-source tools for AI coding agents and small native apps. Everything below is MIT-licensed.

## Agent skills

| Project | What it does |
|---|---|
| [stock-images](https://github.com/jeanpfs/stock-images) | Search and download stock images from Pexels, Unsplash and Pixabay |
| [agent-mobile](https://github.com/jeanpfs/agent-mobile) | Automate iOS simulators and Android emulators through Maestro |
| [db-manager](https://github.com/jeanpfs/db-manager) | Safe PostgreSQL access from project `.env` files, with confirmation gates |
| [xd-extract](https://github.com/jeanpfs/xd-extract) | Extract SVG vector art from Adobe XD share links and `.xd` files |

```bash
npx skills@latest add jeanpfs/stock-images --all -g
```
